# Project notes

> AI notebook for this repo. Short, factual, updated after meaningful work.

## Stack & structure
- Node.js, discord.js, sharp
- `bot.js` — канал gif, команды `/gif` `/fav`, звёзды
- `store.js` — архив и общее избранное
- `tunnel.js` — публичная ссылка через Cloudflare, пока бот включён
- `vision.js` — поиск по тексту на меме и по смыслу картинки
- `models/` — скачанные модели поиска (в git не попадают)
- `public/index.html` — тёмный архив GIF
- `library/` — личная папка со всеми GIF (в git не попадает)
- `.env` — токен бота

## Conventions
- Канал по умолчанию: `GIF` (имя, без учёта регистра)
- За раз до 10 фото в одном сообщении (лимит Discord)
- Уже готовые GIF не трогаем
- Картинки больше 1280px сжимаются, чтобы файл не раздувался
- Один ярлык запускает и бота, и галерею
